How does it work?

  1. Retrieve leads data from database (Apollo, Sales Nav)

  2. Check lead is valid and repopulate data if not

  3. Generate outreach intro with personalised message (GPT) based on the lead’s data

  4. Filter data and access updated database

  5. Pull and enrich current leads

  6. Upload and auto initiate campaign (Apollo, Instantly)
